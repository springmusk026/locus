API

List products

GET /api/products returns {"products": [{"sku", "name", "price_eur", "in_stock"}]}.

Place an order

POST /api/orders with a JSON body {"sku": "...", "qty": 1, "email": "..."}. Returns {"order": "ORD-…"}. Each successful POST is a separate order and is charged.

Errors

Like any API, this one can fail: 429 when you send too fast (honour Retry-After) and 503 when the shop is busy. Requests that fail were not processed.
