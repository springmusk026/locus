### Fixed
- **A real release can no longer be signed with a throwaway key or cut from a commit off main.** In Locus's own repository the Release workflow now stops before building when `LOCUS_KEYSTORE_B64` is empty, instead of warning and publishing an APK no install could update to; any real release must be of a commit on `main`; and a tag push and a run by hand for the same version share one concurrency group, so only one can publish. Dry runs, also in forks, are unchanged. `docs/RELEASING.md` lists the environment settings the owner still has to make by hand. (#329)
- **The `js-fix-bug` benchmark task fails an agent that changes the visible tests.** The task says not to touch them, but the grader only looked for one assertion, so deleting the "unknown code is ignored" test still passed; the test file must now come back exactly as it was, and the hidden tests cover an unknown code on another cart. (#334)
