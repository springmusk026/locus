### Fixed
- **Files attached in a project chat reach the agent.** A file or photo attached in a chat that belongs to a project was copied to the workspace's `inbox/`, and the agent was told `inbox/<name>`; but a project chat's tools only see the project's folder, so the agent couldn't find it. Attachments in a project chat now go into `inbox/` inside the project's folder, under the path that chat's tools and Linux's `/workspace` resolve. Files attached in a new chat before it's moved into a project (or out of one) are brought along when it moves. Chats outside projects and the home composer are unchanged, and nothing already sent changes. No database change. See [projects](docs/design/projects.md#workspace-folder). *Not yet tried on the phone.*
