### Fixed
- **Secret fields no longer teach the keyboard your keys, and the backup password is checked.** Every field that holds a key, token or password (onboarding's API key and MCP token, a provider's keys, header values and proxy password, a local MCP server's environment values, integration keys, SSH passphrases and passwords, ntfy tokens, a PDF's password) is now the design system's password field: masked with a show/hide button to check a paste, with the keyboard's suggestions, learning and autocorrect off. Onboarding's API key is trimmed as it's pasted, so a trailing space no longer fails the model list. The backup password has show/hide, says when it's too short, refuses ones anyone would try first ("aaaaaaaa", "12345678", "password1") with a strength meter under it, and keeps both fields when the phone turns. A new design-guard rule stops a masked field outside the design system from coming back. *Not yet tried on the phone.* (#352)
- **Deleting and removing ask first where they can't be undone.** Deleting a file from a connected folder in Workspace now asks before it goes from your phone's storage (and anything that syncs the folder); Locus still keeps a copy in Trash. Removing an SSH machine asks before its key or password and trusted host key are deleted, and onboarding's Remove key asks as Settings does. Revoking a remembered approval and forgetting an app's answer in Settings → Automation stay one tap, with Undo on the message that follows. *Not yet tried on the phone.* (#353)
- **Forms keep what you typed when the phone turns, and a task can start at a time of day.** The task editor (with its draft), a memory note being edited, the PDF password, an SSH machine being edited and the backup password sheet now survive a rotation or a theme change, and an audio file keeps its place and keeps playing. A new task has **Starting at**: right after saving, or a time picked on a clock, so "every day at 07:30" can be set; the sheet lists the next three runs with the phone's time zone. An edited task keeps its timing. Settings → SSH's host and port get an address keyboard and a number pad and stack at large font sizes, as in onboarding. The audio player opens its file off the main thread. *Not yet tried on the phone.* (#354)
