### Changed
- **CI stops coverage from falling and checks new code with detekt.** The unit-tests job now runs `:koverVerifyUnit`, which fails when merged line coverage drops under 59% (it is 59.6%); the bound is one constant in `build-logic`. [detekt](https://detekt.dev) 2.0.0-alpha.6 with the Compose rules 0.6.8 runs in every module inside the existing lint job, with detekt's default rules, including the complexity limits #359 needs (cyclomatic complexity, long functions, large classes), and a baseline per module, so the 3,097 findings already on main are recorded and only new code has to pass. No new CI job. How to run it and update a baseline: CONTRIBUTING.md and [CI](docs/design/ci.md#static-analysis). A plan for a baseline profile and a startup benchmark, for a decision, is in [docs/design/baseline-profile.md](docs/design/baseline-profile.md). Nothing changes in the app. (#331)
