### Fixed
- **The chat and home do less work while pages load and tools run.** A chat rebuilt its whole state (and re-marked every message) on each percent of a page load in its browser; it now changes only when what it shows of the browser does: whether there's a page, its title, its address and a hand-off. A chat on a cloud model no longer rebuilds its transcript when an on-device reply ends in another chat. Home no longer re-maps every chat row at each tool call of every chat: only the featured card follows the tool in use. Home also ignores the chat list being re-sent unchanged (a helper chat's progress writes to the same table), and an open search runs again only when a chat's title or last activity changes. No database change. See [transcript reads](docs/design/transcript-reads.md). *Not yet tried on the phone.* (#342)
- **Background work held while the phone was hot is no longer stuck.** Chat titles, follow-ups and lessons held while the phone was hot could stay held for good, with a stale "Paused: phone is hot" chip, when the phone cooled at the moment the work was put on hold: the release had already run. Whether to hold is now decided under the same lock as the release. Work held for heat is also released at once only below "Warm"; at "Warm" it waits a minute below "Hot", so a phone going back and forth no longer releases everything at each dip and heats up again. Settings → Battery & heat now shows "offline" for a phone without a network at launch (it said Wi-Fi), and "charging" only when plugged in (a full battery off the charger said charging). See [battery and heat](docs/design/battery-thermal.md). *Not yet tried on the phone.* (#343)
- **Big PDFs open quickly and zooming in no longer runs out of memory.** Opening a PDF read the shape of every page before showing anything, so a 1,500-page file showed a blank screen for seconds; now only the first page is read, the rest as they appear, with a spinner while a slow file opens. Each page image is capped at 16 megapixels (a tall page could take 268 MB at 3×), only the pages actually on screen render sharper when zoomed in, and kept pages are limited to 64 MB, one size per page. See [artifacts](docs/design/artifacts.md#the-pdf-viewers-memory). *Not yet tried on the phone.* (#355)
