### Fixed
- **A local model server no longer gets the catalogue's context window, and o1-preview no longer counts as having tools.** For a model served from LM Studio, Ollama or vLLM on your phone, LAN, Tailscale network (`100.64.0.0/10`), `.lan` or `.home.arpa` name, Docker host or IPv6 private address, Locus looked the model id up in the models.dev catalogue anyway, so `openai/gpt-oss-20b` at 8K was treated as 131K and never compacted in time. Local hosts now get no catalogue entry, so the window you set (or the model reports) is used. `o1-preview` was also listed as taking tools and images; like `o1-mini`, it takes neither. (#344)
- **Rewind no longer says a `call_tool` reached an outside service.** Every call made through tool discovery was listed as outside the phone, so a chat that only read the weather warned about it, while a discovered `ssh_exec` or `git_commit` was shown under the wrong kind. The preview now looks at the tool the call names: commands are commands, MCP tools are outside, and reads such as a web search, the weather or a mailbox leave no entry. (#349)
- **A workflow with no tools listed no longer means "no limit".** Such a workflow could use any tool, and its schedule sheet said it ran fully unattended even if its steps wrote files. Now every call that changes something asks (and is refused on a schedule), the editor and the schedule sheet say so, a plan note over 32,000 characters once the inputs are filled in is refused rather than sent, and workflow ids are checked wherever they become a file name (`../x` can no longer reach another file). (#350)
- **A backup from a newer Locus is refused when only its settings or files are newer.** The backup's content version was written but never compared, so a backup from a newer phone with the same database restored without a word and dropped the settings this version doesn't know. It now stops with "update Locus, then try again" before anything is replaced. (#351)
- **Typos and plurals in translations.** Fixed repeated words in English, Spanish and Portuguese texts ("solo solo", "in in", "com com"), and converted 65 counts ("3 failed", "1 more", "2 of 5 checks…") to proper plurals in every language, so a count of 1 reads right in Spanish and Portuguese too. Percentages stay as they are, and lint's Portuguese "leem" and the `album.read` permission name are marked as not typos. (#356)
- **Tests that need a newer `sqlite3` skip with a reason instead of failing.** The search migration tests and `SearchTextTest` run the host's `sqlite3`, whose SQL needs 3.44; on a host with 3.40 they failed with `near "ORDER": syntax error`. They now skip and say which version they found (on CI they still fail). TESTING.md explains how to give Robolectric a writable home. (#357)
