### Fixed
- **`find_tools` finds camelCase and Chinese, Japanese, Korean and Thai tools.** The search lower-cased names before splitting them, so `createIssue` was one word and `create issue` found nothing (most MCP servers name tools in camelCase), and a description with no spaces (`设置闹钟和提醒`) was one word too. Names are now split at case changes (and kept joined as well), runs of those scripts are matched by pairs of characters, and `running` and `setting` now meet `run` and `set`. Tool lists and descriptions sent to the model don't change. (#345)
- **Compaction counts Chinese, Japanese and Korean text properly and no longer splits an emoji.** The token estimate was four characters a token for every script, so 2,100 Chinese characters counted as 525 tokens, and the user messages a summary keeps could fill a small window or overflow it right after compacting. A CJK character now counts as one token, and a long kept message is cut between whole characters, so no half an emoji is sent on every request. (#346)
- **Saved tool output no longer disappears during a long run, and two saves can't share a name.** Only the newest 30 files in the workspace were kept, so a task that saved more could point the model at a file already deleted, and two saves in the same second overwrote each other 1 time in 4,096. Names are now never reused in a session, and files saved in the last 6 hours are not deleted. (#347)
- **A busy memory index is no longer deleted.** Any search-index error, even a passing "database is locked" when two memory saves raced, deleted the index and, after three, switched ranked memory search off until the app restarted. Now only a damaged index is rebuilt; a busy one is waited for (3 s) and retried, and other errors keep the file. (#348)
