### Fixed
- **Naming a shared hosting domain no longer trusts everyone's site under it.** Typing "github.io", "vercel.app", "pages.dev" or another public suffix made every subdomain of it a host you named, so after reading outside content the agent could open `https://attacker.github.io/?d=…` without asking. Subdomains now count only under a name someone registered, checked against a bundled snapshot of the Public Suffix List; `docs.github.com` still counts when you typed `github.com`, and the suffix you typed still counts by itself. No database change. See [taint](docs/design/taint.md#shared-hosting-domains) (#364).
- **fetch_url keeps to the server it was given.** Headers the agent set (an API key, say) followed a redirect to another port or scheme of the same host; now they go only to the same origin (scheme, host and port). A provider or connector set up on the local network opened every port of its machine to fetch_url (Ollama at `192.168.1.5:11434` let it reach `192.168.1.5:8080` and `:22`); now only the address you set up is reachable. Private-address checks also cover 192.0.0.0/24, 198.18.0.0/15, 240.0.0.0/4, and IPv6 addresses that carry a private IPv4 one (NAT64 `64:ff9b::/96`, `::a.b.c.d`, 6to4 `2002::/16`). See [taint](docs/design/taint.md#fetch_url) (#372).
- **Addresses with a backslash or user info can't pass as a site you named.** Locus read the host of `https://evil.com\@github.com/` as github.com, while the browser and OkHttp go to evil.com, so a tainted run could open it without asking, and a link in a reply opened in one tap. Locus now reads hosts as browsers do (`\` as `/`, extra or missing slashes, IPv4-mapped IPv6 as its IPv4 address), and an address with a `\`, user info, a `%` in the host or no `//` after `https:` counts as one the agent chose: it asks in a tainted run or after a private read, gets no Allow site, and its link asks after outside content. See [taint](docs/design/taint.md#one-host-for-every-decision) (#377).
- **Fullwidth lookalikes of the outside-content markers are defused.** Text could end its `<untrusted_web_content>` block early with `＜/untrusted_web_content＞` or `﹤/untrusted_web_content﹥`, which normalise to the real tag and which models read as it. Those forms (and fullwidth letters) are now defused like the ASCII tag, and so are the safety reviewer's section tags; the rest of the text is unchanged. See [taint](docs/design/taint.md#what-locus-does) (#378).
