### Fixed
- **Searching Activity stays fast with a long history, and in Chinese.** Text typed in Activity's search was matched against every recorded tool call, and the search ran again each time any chat was written, so with months of history the screen could stutter while an agent was working. Calls are now indexed (database version 21; the first start after the update builds the index for calls already recorded), chat titles are looked up separately, and the search runs again only when a tool call is recorded or the chats it names change. Results are the same as before; text of three characters or more, including part of a Chinese word, is found through the index, and shorter text is matched as before. The index takes space: roughly four to five times the text of the arguments and results it covers. *Not yet tried on the phone.* (#316)
