### Fixed
- **A finished model download is no longer deleted on Resume, and Pause works while it's checked.** If Locus was stopped while it checked a finished download from a URL with no published size, Resume asked for bytes past the end, the server said there were none, and the whole file was deleted. Now a file that's already complete is kept and checked. The row says it's checking the file as soon as the last byte arrives (it showed 100% for tens of seconds), Pause during the check keeps the file and installs nothing, and a download whose connection ends early is resumed instead of installed half-received. *Not yet tried on the phone.* (#309)
- **Local GGUF replies no longer end with part of a stop marker.** A chat template's end marker (`<|im_end|>`, `<end_of_turn>`) that came over two or more tokens let its first part (`<|im_`) through to the reply. Text that could start a marker is now held back until the next tokens show whether it is one, and long replies no longer slow down token by token from re-copying the whole reply. *Takes effect once the native libraries are rebuilt; not yet tried on the phone.* (#310)
- **Linux command output keeps accented letters, Chinese and emoji whole.** Output is read 8 KiB at a time, and a character cut between two reads became "��" for both you and the model; a long output's kept start and end could also cut an emoji in half, and a service's log tail could start mid-character and came out shorter than asked for non-English text. All three now come out whole. *Not yet tried on the phone.* (#311)
- **A Linux command that leaves a program running no longer hangs its tool call.** A command that started a background program (`npm run dev &`) could keep the tool call waiting forever, even past its timeout, because that program held the output open. Locus now reads for at most 2 more seconds after the command ends or is stopped, then returns. Stopping also finds the process id another way when the first fails, so proot still gets the signal that lets it end what it started, and logs when it can't. *Not yet tried on the phone.* (#312)
