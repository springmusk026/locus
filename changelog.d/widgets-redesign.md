### Changed
- **The home-screen widgets fill their space and speak your language.** Both widgets used one layout stretched to any size, so a 4×2 status widget showed "Idle", one cut line and an empty gap, and the usage widget two lines and blank space. Each now shows what fits its size. The status widget gives the latest scheduled task its own line with its title and when it ran ("Morning digest · 7:02"), then as many lines of its answer as fit, and while Locus is idle the next task at a time of day ("Next: Evening recap · 18:00"). The usage widget adds today's tokens and requests and, when taller, the last seven days as bars with their total ("7 days · $14.20"), in dollars when every day had prices and in tokens otherwise. With Lock Locus on the status widget no longer shows task titles either, only that a task ran, how it ended and when. All the widgets' text is now in Spanish, Portuguese and Chinese too, with numbers, money and times written the language's way and times following the phone's 12/24-hour setting. Nothing new is stored, no database change, no periodic updates; the status widget now does no work while none is placed. See [the widget](docs/design/android-bridge.md#the-widget). *Not yet tried on the phone.*

### Fixed
- **The usage widget no longer says "cost unknown" when prices are on.** Prices come from the models.dev catalogue, which Locus loaded only when a chat, Insights or a run with a budget asked for it; in a process Android had started for the widget or a scheduled task, no request had a price and the widget showed only tokens with "Today · cost unknown" until Locus was opened. The widget's figures now load the saved catalogue themselves. See [the usage widget](docs/design/android-bridge.md#the-usage-widget). *Not yet tried on the phone.*
- **The status widget shows the next run of a task on a plain period.** A daily task saved before tasks could run at a time of day (such as a morning digest made before 26 November) has no fixed time, so the widget showed no "Next" line for it. It now shows the earliest time Android may run it, one period after its last run ("Next: Morning digest · tomorrow 2:46 PM or later"). The usage widget's bars also take the height left over, so a tall tile has no empty band. *Not yet tried on the phone.*
