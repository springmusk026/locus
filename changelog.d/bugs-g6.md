### Fixed
- **Long numbers that aren't card numbers can be typed in the browser.** Any run of 13 to 19 digits counted as a card number, so the agent couldn't type a tracking number, an order number, a millisecond timestamp or a phone number with its country code. A number is now refused as a card only when it starts with a card network's prefix and passes the card checksum (Luhn); real card numbers, spaced or dashed, are still refused. (#318)
- **What you type in a chat and haven't sent is kept.** The composer's text was lost when you left the chat, and Edit on a message, a queued message or a plan replaced it. The text is now kept per chat, also after a restart, and shows as "Draft: …" in the chat list. Editing a message sets it aside and gives it back when you send or close the edit, Back closes an edit or the Aside switch before leaving the chat, and a plan's Edit starts "Change the plan:" (in your language) only in an empty composer. A temporary chat's draft is never written to disk. (#319)
- **Long chats scroll more smoothly, and a steer no longer yanks you to the bottom.** Each reply looked through the rest of the transcript on every update to find its task, so long chats did work that grew with the square of their length. That now happens once per update. Sending a message while reading further up kept jumping to the end; your place now stays, and "jump to latest" takes you down. (#321)
- **Run anyway no longer starts an empty turn when it's refused.** On an idle chat, when the call was refused at the last moment (its tool gone, or a limit now saying no), Locus still started a turn, which asked the model again with nothing new. Now the chat says why and nothing is sent. (#337)
- **Deleting a chat stops what runs in it.** A chat deleted while its task ran kept running and spending tokens, its helpers carried on, and Locus kept its run state, browser tabs and picked element in memory. Deleting now stops the run and its helpers first, closes the chat's browser tabs, drops everything kept for it and deletes its draft. Clear browsing data now also forgets the addresses you typed and the element you picked. (#338)
- **An edit or retry while the chat is busy says so, and an answer to a closed question isn't lost.** Edit and regenerate did nothing while the chat was still working, and Edit cleared your attachments all the same. The chat now says it wasn't sent, and your text, the edit and the attachments stay. A message typed as the answer to a question that had just closed (answered from the notification, say) was dropped; it's now sent as a normal message. (#339)
- **Taking over the browser follows the chat you took.** A browser step waiting behind another one could still act on the page after you took over; it now checks again and waits for you. Hand back, Done and leaving the browser released whichever chat was on screen then, so after switching chats the one you took stayed blocked for five minutes; they now release the chat you took. The browser also no longer keeps a closed screen in memory. (#340)
- **After a task, Locus uses your latest settings and keeps your chat's name.** The lesson-saving reflection after a long task used the settings and chat from the start of the task, so turning Learn after tasks off or setting memory to always ask during the task didn't stop it. It now checks again when it starts. A title generated after the first reply replaced a name you gave the chat while it was being made; it now only replaces the name it was made for. A chat that had a scheduled run stayed marked as one after the run ended. (#341)
